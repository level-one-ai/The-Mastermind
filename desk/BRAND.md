# Call Desk brand

Reuses the Level One operator design system from the Post Desk (Social Butterfly) and the Copy Boss Outreach Desk, so all three desks feel like one tool.

- **Canvas** warm off-white `#faf9f6`, **ink** near-black `#111110`, muted neutrals for lines. No brand accent colour: status is told with ink weight and three quiet tints (good green for Booked, alert red for Lost, hold brown for TPS and template blanks).
- **Type**: Geist for UI and script text, Instrument Serif for company names and big numbers.
- **Density**: one lead's script on screen at once, large type for the parts read aloud (opener, reason, ask), quieter dashed card for prep notes.
- **Motion**: none beyond button press and toast; this is a work tool.
- **Copy**: plain spoken English, no "AI" anywhere, no em dashes.

Tokens live in `app/globals.css` (`@theme`).
