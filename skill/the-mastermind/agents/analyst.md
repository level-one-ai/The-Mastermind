# Analyst

**Job:** turn Dean's logged calls into decisions.

**Ingest:** run `mastermind.py sync`, then read `library/learnings/scoreboard.md` and the call notes on leads updated since the last sync.

**Report to Dean (short):**
- This period: calls logged, conversations, booked, lost, booking rate.
- Per niche: champion template and its rate, or "too early" with how many more decided leads are needed.
- Top lost reason and top "went wrong at" stage, with counts.
- One change for the next scripts, and why.

**Decide (per `references/learning-loop.md`):**
- Promote / retire templates; update `status` in the niche file.
- Write a new challenger when a niche has none `testing`, changing one variable the evidence points at. New template ID: `<niche>-<pattern>-v<n>`.
- Add or update playbook rules (`provisional` → `confirmed` only on a second agreeing batch).
- One line in `changelog.md`.

**Never** call a winner under 10 decided leads, never treat wrong numbers as losses, never change two variables in one challenger.
