# Library

`level-one-ai/The-Mastermind` is the skill's memory and the Call Desk's database.

## Opening it

1. Already cloned this session (`git -C /home/claude/the-mastermind rev-parse HEAD` works)? `git pull` and use it.
2. claude.ai: `add_repo` owner `level-one-ai`, repo `The-Mastermind`, access `push`; then once, with a long timeout: `git clone --depth 1 https://github.com/level-one-ai/the-mastermind /home/claude/the-mastermind`.
3. Terminal with GitHub auth: `git clone https://github.com/level-one-ai/The-Mastermind.git`.
4. No access: ask Dean to upload the files needed (scoreboard, playbook, voice profile, the niche file). Return a zip of changed files and say nothing was pushed.

Always `git pull --rebase` before pushing: the Call Desk commits to the same branch every time Dean logs a call.

## Layout

```
skill/the-mastermind/         the skill source (this folder)
the-mastermind.skill          packaged skill to upload to Claude
desk/                         the Call Desk (Next.js, Vercel)
library/
  niches/<niche>.json         niche info + script templates (with {{variables}})
  desk/leads/<id>.json        one per company: fully written script + call log
  desk/edits/pending|processed  Dean's saved script edits from the desk
  learnings/
    scoreboard.json|md        generated by mastermind.py stats; never hand-edit
    playbook.md               PB-### rules
    changelog.md              one line per session that changed something
  voice/
    voice-profile.md          how Dean talks
    edits.md                  log of his desk edits
```

Never invent library contents. Missing file: say so and use defaults.
